# 運用ワークスペース（0.44）

Docker コンソールの Connections / System と Settings で接続設定、保存、復元、診断、ポリシー確認を行えます。モデル提供元4種に対応し、新しい HTTP/MCP ツールは初期状態で禁止されます。操作・リソース・マスキングを確認してください。詳細設定は JSON で編集します。

保存は即時適用ではありません。新しい宛先認証情報は状態ボリュームの 0600 ファイルに保存され、再表示されません。空欄なら既存情報を保持します。コンソールのオリジン、ゲートウェイ認証、ブローカーの信頼設定は配置ファイルで管理します。

```bash
docker compose stop app envoy
docker compose run --rm app activate-config
docker compose up -d app envoy
```

メンテナンス時に両サービスを停止して適用します。稼働中のアプリへの適用は拒否しますが、別管理の Envoy の停止は確認できません。経路変更時は経路ポリシーを既定値に戻します。アカウント・キー・監査を保持します。過去10件の復元は適用待ちとなり、存在する場合はポリシーも復元します。秘密ファイルは復元用に保持され、外部ファイルは再マウントが必要です。接続は保存状態が優先され、認証の信頼設定は配置ファイルを使用します。

診断は検査器・Envoy リスナーと要求の段階・状態・回数・時刻を示します。ネットワーク分離を迂回せず、宛先認証の成功も断定しません。回数は再起動でリセットされます。イベントと照合してください。最大 8 KiB の合成 JSON によるプレビューはローカルポリシーのみで、宛先送信・認可・ポリシー変更・承認生成を行いません。判定・理由・エンティティ種別のみ返します。

初回確認：固有パスワードで設置 → 独立した認証情報 → 許可・合成個人情報・禁止要求 → イベント確認 → 再起動と保持 → 復元。顧客の実 MCP とアカウントは別途検証が必要です。
