# 运维工作区（0.44）

Docker 控制台在 Connections / System 和 Settings 中提供配置向导、暂存、恢复、诊断及策略预览。支持四个模型提供方；新 HTTP/MCP 工具默认阻止，请检查操作、资源和脱敏字段。高级映射使用 JSON。

保存不改变实时流量。新目标凭据写入状态卷的 0600 文件，不再显示。留空保留原凭据。控制台源、网关认证和代理信任由部署文件管理。

```bash
docker compose stop app envoy
docker compose run --rm app activate-config
docker compose up -d app envoy
```

维护时停止两个服务后应用。应用命令会拒绝运行中的应用，但不能确认外部 Envoy 已停止。路由映射更改会重置路由策略。保留账户、客户端密钥和审计。最近十个版本可恢复为待应用配置，并在可用时恢复策略快照。凭据文件保留以支持恢复；外部凭据须重新挂载。状态中的连接配置优先于部署文件，但身份信任仍来自文件。

诊断仅显示检查器和 Envoy 监听器及请求阶段、状态码、次数、时间，不绕过网络隔离。监听器就绪不证明目标认证；计数器在重启后重置。请结合流量事件判断。策略预览仅检查本地内容和路由，使用最多 8 KiB 合成 JSON，不调用目标、不验证代理授权、不修改策略或创建审批。仅返回决策、原因和实体类型。

首次验证：安装并设置唯一密码 → 配置独立凭据 → 允许、合成个人信息和阻止请求 → 查看事件 → 重启验证持久化 → 恢复。客户真实 MCP 和账户需要单独验证。
